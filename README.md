# Amalan Muslim RC71 V7.0 — iPad 10.9 Edition

Versi ini adalah paket **GitHub Pages-ready** berbasis baseline RC71 V6.1.9.

## Struktur

```text
AMALAN_MUSLIM_RC71_V7_0_IPAD_10_9_GITHUB/
├── index.html      # aplikasi lengkap
├── README.md       # panduan GitHub/GitHub Pages
└── .gitignore
```

## Fitur inti yang dipertahankan

- Daftar isi dan urutan bacaan RC71
- Fokus dan Auto Fokus
- Auto Scroll
- Smart Counter dengan floating controls dan target double beep
- PDF Reader dan PDF Visual Auto Scroll
- Media Galeri
- Catatan dan Library Bacaan
- Mode tema
- Fullscreen
- Kontrol font

## Optimasi iPad 10.9

- Layout responsif khusus layar tablet
- Font bacaan lebih nyaman
- Tombol lebih besar dan touch-friendly
- Landscape dioptimalkan sebagai mode utama
- Bottom navigation lebih lega
- Fullscreen landscape menggunakan right navigation rail
- Safe-area iPadOS diperhitungkan

## Upload ke GitHub

1. Buat repository baru di GitHub, misalnya `amalan-muslim-ipad`.
2. Upload seluruh isi folder ini ke root repository.
3. Pastikan file utama bernama **`index.html`**.
4. Commit perubahan.
5. Buka **Settings → Pages**.
6. Pada **Build and deployment**, pilih **Deploy from a branch**.
7. Pilih branch `main` dan folder `/(root)`, lalu Save.
8. Setelah deployment selesai, buka alamat GitHub Pages yang diberikan GitHub dari iPad.

## Catatan PDF

PDF visual reader/teleprompter menggunakan PDF.js dari CDN. Saat GitHub Pages dibuka online, engine PDF dapat dimuat dari CDN tersebut.

## Penting tentang penyimpanan

Data lokal seperti catatan atau hasil pengeditan bergantung pada browser/site storage. Jangan menghapus data website di Safari/iPadOS jika ingin mempertahankan data lokal. Untuk distribusi jangka panjang, lakukan backup/export bila tersedia di aplikasi.

## Rekomendasi penggunaan iPad

- Landscape untuk membaca dan Auto Fokus.
- Tambahkan situs ke Home Screen bila ingin akses seperti aplikasi.
- Gunakan GitHub Pages HTTPS agar fitur browser modern berjalan lebih konsisten.
